# Release v1.1.0

R code and preserved analysis inputs accompanying the revised manuscript “Leiomyosarcoma-Enriched Myogenic Axis in Public Sarcoma Cohorts.”

This release contains five sequential R scripts, the S1 Data workbook, fixed configuration and gene sets, and the nine historical prepared GEO matrices distributed as ten binary parts. R automatically restores the historical inputs or downloads the same parts when using the small journal code archive. TCGA inputs are downloaded from a fixed cBioPortal datahub commit and checked before use.

The primary expression reconstruction and the separate online RMA reconstruction remain distinct. The historical preprocessing versions are incompletely documented, and connected-record groups are not confirmed unique patients.

Download the full source archive to obtain the code and historical input parts together. The optional S1_Code.zip release asset contains the five scripts and small supporting inputs; keep S1_Data.xlsx beside its extracted folder.
