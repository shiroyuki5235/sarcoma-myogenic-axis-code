# Release notes: v1.0.0

This release contains the R analysis code associated with the manuscript **“Leiomyosarcoma-Enriched Myogenic Axis in Public Sarcoma Cohorts.”**

Included materials:

- Four R scripts for input preparation, GEO discovery analysis, additional discovery analyses, and TCGA-SARC external validation.
- README and repository metadata.
- Citation metadata for GitHub and Zenodo.
- Input and output documentation.
- MIT license.

Raw input data and large generated outputs are not included. Users should obtain public datasets from the original data sources and prepare the expected input directory structure before running the scripts.
